# ENJAZ — GitHub Pages

## Files
Upload every item in this folder to the ROOT of your GitHub repository.
Do not upload the ZIP itself as the only file; extract it first.

## Publish
1. Create a new repository on GitHub.
2. Upload all files and the `icons` folder from this package.
3. Open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL to appear.

## First connection
Open the published website. Enter the Google Apps Script Web App URL and the app's secret token when prompted.
The URL must be the deployed Web App URL ending in `/exec`.

Important: Keep the repository private if the source code should not be public, but confirm your GitHub plan supports Pages for private repositories before relying on it. Never place passwords or private tokens directly in the HTML source.
